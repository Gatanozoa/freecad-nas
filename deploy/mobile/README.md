# 移动端 0.5.2

会话页默认打开最近会话。使用「新建对话」可以打开独立草稿。任务记录保留各阶段及发生时间，点击展开查看。服务端断线后可以在会话中重试，已受理的建模任务会沿用原任务编号。模型库每个项目显示一张卡片，打开后可切换版本。

移动端编辑时打开独立输入栏。可见区域变化时，编辑栏紧贴屏幕键盘上方。关闭输入栏后，草稿和会话位置会保留。

整表确认会显示建议尺寸和复核说明。必要尺寸缺失、确有冲突或结构不明确时才进入追问。已有的待补充任务可以在原会话重新提交一次，生成新版的尺寸确认卡。

## 更新已有 NAS 项目

1. 保留原项目名称、`.env` 和 `mobile-data` 数据卷。
2. 用本目录的 Compose 文件替换原 Compose。
3. 如果 `.env` 内有 `MOBILE_VERSION`，改为 `MOBILE_VERSION=0.5.2`；其余配置保持原值，尤其不要重新生成 `MASTER_KEY`。
4. 拉取新镜像并重新部署 app、orchestrator 两个容器，单纯重启不会更新镜像。
5. 浏览器刷新页面；若已安装到桌面，关闭后重新打开。若页面仍为旧版，在设置的「连接与存储」中点击「检查更新并刷新界面」。

镜像：`ghcr.io/gatanozoa/freecad-mobile:0.5.2`。无需本地构建或单独拉取 Python 镜像。FreeCAD 服务无需随此次界面升级更新。

新部署才使用 `.env.example` 生成 `.env`。升级时不要用示例覆盖真实配置。

## 同时通过域名和局域网 IP 访问

在已有 `.env` 增加（将域名改成自己的）：

```env
PUBLIC_URL=https://cad.example.com
ALLOWED_ORIGINS=http://192.168.1.100:8089
MOBILE_VERSION=0.5.2
```

PUBLIC_URL 自动加入白名单，ALLOWED_ORIGINS 可用英文逗号追加多个完整来源（协议、主机、非标准端口）。不要填写路径、通配符或结尾斜杠。
重新拉取并部署 app、orchestrator 使环境变量生效。无需改动 CAD_URL、MASTER_KEY 或数据卷。
各地址独立登录；HTTPS 域名登录使用 Secure Cookie，白名单 HTTP 局域网地址使用普通 Cookie，均启用 HttpOnly、SameSite=Strict。
页面和 API 仍由同一来源提供，此设置不是跨域 API 的 CORS 开关。不要通过 Caddy 改写或删除 Origin 请求头。

## 0.4.0 键盘适配

输入栏跟随浏览器实际可见区域调整；键盘弹出时隐藏底部导航及固定测试快捷入口，输入和发送按钮保留可见；收起键盘后恢复。兼容仅缩小 visualViewport 的 Android WebView 行为。更新后关闭桌面入口再重新打开以加载新页面。

## 0.4.0 桌面入口与键盘兼容

静态资源增加版本标识并要求缓存重新校验。设置页显示客户端及服务端版本，并提供“检查更新并刷新界面”。
支持浏览器报告的可见区域或虚拟键盘几何信息；如果网页接收不到键盘位置，独立编辑栏会为键盘预留一段空间，仍可手动收起。
设置 → 连接与存储 → 键盘与窗口诊断可查看最近的窗口变化；不采集输入内容、账号或模型 Key。请先在会话页复现，再打开诊断。
更新后若客户端版本仍旧，先退出所有同域网页和桌面窗口，再重新打开；必要时清除该站点缓存（可能需要重新登录，但 NAS 数据保留）。Via 与桌面 WebView 的最终体验仍需真机确认。

## 0.4.0 尺寸采集与确认

模型提示词内置 mobile/rules/measurement.md 的测量规则，随镜像安装，无需另配 Skill。
- 照片无比例、标注模糊、缺厚度/深度/孔径/孔位、装配接口不明、螺纹规格不明、单位或尺寸冲突时，先追问并说明测量方法。
- 参数记录包含值、来源（用户/图纸/建议估算/未知）、是否必要、测量提示。缺必要参数或有矛盾时，不提交 CAD。
- 参数完整后先显示尺寸确认卡片，包括估算值和假设；点击确认后执行已存脚本，通常无需再调模型。用户补充或修改后重新整理卡片。
- 完整的固定零件测试继续直接执行。尺寸确认与模型生成后的三维草稿确认是两个步骤。
- 追问沿用历史尺寸、问题和参考图，支持逐次补充。旧版本卡片不能确认新版本。刷新或重启不会丢失待确认清单。

是否提取到正确、完整的参数仍依赖所选模型的图文理解，确认清单与生成后的模型均需用户核对。
